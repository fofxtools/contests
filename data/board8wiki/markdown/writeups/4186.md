This was the first match of Portal's all contest where it didn't act like it had joke trends. It won the very very early vote, fell down to the 55-45 range and the match just stayed there all day. The possibility of Portal upsetting RE4 here died when Mass Effect did so well on it, but Portal still had one hell of a contest here. There is no shame in losing 55-45 to RE4, especially when the stats from LOL 4-ways have this match as 63-37. 4-ways aren't legitimate in any way, but a statistical jump that large is no accident, especially against a game like RE4 that got the contest title boost.

What we learned from this match and Portal's run in general: If you want to make gamers happy, give your game away for free.
