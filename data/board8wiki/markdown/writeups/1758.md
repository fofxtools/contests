This could very well be the easiest analysis ever. Cloud did exactly as expected against Vyse, and the only thing of note about the match was Cloud once again giving up the early lead in the poll.

The only thing anyone card about in this match were Cloud/Link comparisons, and honestly, Cloud did not impress me here. While Link was busy putting a world of hurt on Ganon, Cloud only did as expected against Vyse. "As expected" is not good enough when your main opponent is exceeding expectations. In fact, all Cloud had going for him after this match was the prediction percentage advantage, and that can easily be explained by Link having to deal with CATS, Alucard, and Ganondorf as opposed to Milk Nukem, Vyse, and Laharl. Cloud did not look good here at all.

As they say, one's an accident, two's a trend, three's a problem. Link managed more total votes in an SFF match than Cloud in a pure match. Honestly, assuming transitivity in the finals, what argument could have possibly been made for Cloud at this point?
